# `lib/`

Application source code.

- `main.dart` starts the app inside Riverpod's `ProviderScope`.
- `app.dart` configures the app shell and named routes.
- `app_theme.dart` is the shared source for Material colors and typography.
- `welcome_screen.dart` is the initial screen.

Add feature code in focused subdirectories when those features are implemented;
give each new source directory its own README describing its purpose and flow.
